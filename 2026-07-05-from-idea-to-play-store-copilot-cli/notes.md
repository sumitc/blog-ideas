## Published Links

## Origin Story
- Atlas Junior is a voice-first, local-first geography game for families
- Built and shipped as a single shared codebase across web and Android
- Goal: show how Copilot CLI, Next.js, Capacitor, and Play Console workflow made the first APK possible

## Key Storyline
1. **Ideate and scaffold with Copilot CLI** — terminal-first build workflow
2. **Architecture** — React + Next.js + Capacitor for shared web and Android code
3. **Audio mechanics** — Web Speech API on web, native speech on Android
4. **Local-first feedback loop** — bundled dictionary, API validation, GitHub Actions sync
5. **Test harness and release** — Maestro smoke tests, Play Console, testing track, production gate
