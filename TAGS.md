# Blog Tags Reference

Tags to use when publishing on Medium and Substack. Mix **1–2 broad** + **2–3 specific** per post. Max 5 tags. Always proofread — a single typo silently breaks indexing.

---

## Broad (High-Traffic)

These are the highest-reach tags on Medium. Always include at least one:

| Tag | Best for |
|-----|----------|
| `Technology` | Any tech post |
| `Artificial Intelligence` | Any AI/LLM post |
| `Productivity` | Tools, workflows, building faster |
| `Self Improvement` | Personal growth, habits, mindset |
| `Life Lessons` | Reflective, experience-based posts |
| `Startup` | Building products, entrepreneurship |
| `Leadership` | Career, teams, decisions |
| `Programming` | Code, engineering, dev tools |

---

## Topic-Specific

### AI & Dev Tools
| Tag | Use when |
|-----|----------|
| `ChatGPT` | Posts featuring ChatGPT specifically |
| `Machine Learning` | ML concepts or experiments |
| `LLM` | Large language model posts |
| `GitHub Copilot` | Copilot CLI / coding AI |
| `Software Development` | General engineering posts |
| `Open Source` | OSS tools or projects |

### Product & Building
| Tag | Use when |

| Tag | Use when |

## ⚠️ Tags to Avoid

- Niche tags with low traffic: `#TechHistory`, `#AcquiredPodcast`, `#SmartPlant`
- Anything with a typo — e.g. `Startupş` breaks indexing silently
- More than 5 tags total
